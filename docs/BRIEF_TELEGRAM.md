# Анкета → Telegram: как подключить отправку

Анкета на странице `/brief` собирает ответы клиента. Чтобы они приходили вам в Telegram,
нужны две вещи: **бот** (он пишет вам сообщения) и **посредник** — маленькая бесплатная
функция Cloudflare Worker, в которой хранится ключ бота.

```
анкета на сайте → Cloudflare Worker (хранит ключ) → ваш бот → вам в Telegram
```

Ключ бота нельзя класть в код сайта: код сайта открыт, и любой мог бы рассылать
сообщения от имени вашего бота. Поэтому ключ живёт только в настройках Worker'а.

Пока отправка не подключена, анкета работает в запасном режиме: клиент копирует
ответы и пересылает их сам.

Всё делается с iPad в Safari, примерно за 15 минут. Названия кнопок в Cloudflare
иногда меняются — если что-то выглядит иначе, ищите похожие по смыслу.

## 1. Бот в Telegram

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, «DWeb — заявки») и адрес бота, который заканчивается
   на `bot` (например, `dweb_briefs_bot`).
3. BotFather пришлёт **ключ** вида `1234567890:AA...`. Это пароль от бота —
   никому его не показывайте и не отправляйте в чаты (мне тоже не нужно).
4. Найдите своего нового бота по адресу и нажмите **Start** (или отправьте `/start`).
   Без этого бот не сможет вам писать.

## 2. Номер вашего чата

1. В Safari откройте адрес, подставив свой ключ вместо `КЛЮЧ`:
   `https://api.telegram.org/botКЛЮЧ/getUpdates`
2. На странице найдите фрагмент `"chat":{"id":123456789` — число и есть номер чата.
   Если страница почти пустая (`"result":[]`), напишите боту любое сообщение и обновите её.

## 3. Посредник в Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. Откройте **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»),
   назовите, например, `dweb-brief` и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите весь код и вставьте содержимое файла
   [`worker/brief-worker.js`](../worker/brief-worker.js) из репозитория. Нажмите **Deploy**.
4. Вернитесь к Worker'у → **Settings** → **Variables and Secrets** → **Add**:
   - `BOT_TOKEN` — тип **Secret**, значение — ключ бота из шага 1;
   - `CHAT_ID` — тип **Text**, значение — номер чата из шага 2.

   Сохраните (**Deploy**).

5. Скопируйте адрес Worker'а — он вида `https://dweb-brief.ВАШ-НИК.workers.dev`.

## 4. Подключение к сайту

Пришлите адрес Worker'а (ключ бота присылать **не нужно**). Он записывается в
`src/content/brief.ts`:

```ts
export const briefEndpoint: string | undefined = 'https://dweb-brief.ВАШ-НИК.workers.dev';
```

После публикации на последнем шаге анкеты появится кнопка «Отправить».
Проверьте: заполните анкету сами — сообщение должно прийти от бота.

## Защита от спама

- Скрытое поле-ловушка: боты его заполняют, и такие заявки молча отбрасываются.
- Не больше 5 заявок за 10 минут с одного адреса.
- Принимаются запросы только с сайта `https://tsum323.github.io`. Если сайт переедет на
  свой домен, добавьте в Worker переменную `ALLOWED_ORIGINS` (тип Text) с адресом,
  например `https://example.ru,https://tsum323.github.io`.

Если спам всё же появится, следующим шагом можно подключить бесплатную проверку
Cloudflare Turnstile («я не робот», обычно незаметная для человека).

## Если что-то пошло не так

- **Ключ бота попал в чужие руки** — в @BotFather: `/revoke` → выберите бота, получите
  новый ключ и замените `BOT_TOKEN` в Worker'е.
- **Заявка не пришла** — в Cloudflare откройте Worker → **Logs** (или **Observability**):
  там видны ошибки. Частые причины: не нажали Start у бота, опечатка в `CHAT_ID`.
- **Изменился код посредника** в репозитории — повторите шаг 3.3 (вставить код и Deploy).
