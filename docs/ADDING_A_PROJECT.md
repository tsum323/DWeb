# Как добавить новый проект

Новый кейс добавляется только данными — шаблоны страниц менять не нужно.
Карточка на главной, страница `/work/<slug>`, переход «Следующий кейс»,
карта сайта и метаданные появятся автоматически.

## 1. Скриншоты

Положите исходные скриншоты в `src/content/projects/<slug>/media/`:

| Файл                | Что снять                                     | Размер окна            |
| ------------------- | --------------------------------------------- | ---------------------- |
| `desktop-home.webp` | первый экран на десктопе                      | 1440 × 900, масштаб 2× |
| `mobile-home.webp`  | первый экран на телефоне                      | 390 × 844, масштаб 3×  |
| любые другие        | экраны для глав «Реализация» и «Адаптивность» | так же                 |

Формат исходника — WebP или PNG в полном разрешении. Уменьшенные версии
в AVIF и WebP создаются автоматически при сборке.

## 2. Данные проекта

Создайте `src/content/projects/<slug>/index.ts` по образцу `brass/index.ts`.
Формат описан в `src/content/schema.ts` — редактор подскажет поля,
а сборка не пройдёт, если обязательное поле пропущено.

Правила честности:

- **features** — `status: 'shipped'` только для того, что реально работает.
  Идеи и планы — `status: 'planned'`, они показываются отдельно пунктиром.
- **metrics** — заполняйте, только если есть источник цифры (поле `source`).
  Нет данных — не заполняйте, блок просто не появится.
- **status** — `live` (запущен), `demo` (показан клиенту) или `in-progress`.
- **role**, **scope** — пункты со строчной буквы: они выводятся списком.
- Главы `concept`, `implementation`, `responsive` и блок `design` необязательны:
  без них глава не выводится, а номера остальных глав пересчитываются.

## 3. Порядок

Добавьте проект в `src/content/projects/index.ts`:

```ts
import { brass } from './brass';
import { newProject } from './new-project';

export const projects: Project[] = [newProject, brass];
```

Порядок в списке — порядок на странице «Проекты» (`/work`). На главной показываются
до трёх проектов с `featured: true`. Поле `hook` — одна-две строки для карточки: коротко
и интересно, без подробностей (они — на странице кейса).

## 4. Картинка превью ссылки

```
npm run og
```

Создаст `public/og/<slug>.png` — карточку, которая появится при отправке ссылки
на кейс в мессенджерах и соцсетях. Файл нужно сохранить в репозитории вместе с проектом.

## 5. Проверка

```
npm run build     # типы, сборка и готовые HTML-страницы
npm run dev       # http://localhost:5173/DWeb/work/<slug>
npm test          # автотесты
```

Чтобы новый кейс проверялся всеми автотестами (адаптив, анимации, доступность,
изображения), добавьте его в список `pages` в `tests/support/helpers.ts`.
Карта сайта, ссылки и превью проверяются для всех кейсов автоматически.
