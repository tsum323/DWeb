# DWeb

Портфолио веб-разработчика: сайты для бизнеса — продуманные от сетки до кода.

**Сайт:** https://tsum323.github.io/DWeb/

Концепция «Чертёж»: графит и бумага, один сигнальный цвет, сетка 4 / 8 / 12 колонок,
моноширинные подписи и анимации, которые «собирают» страницу по линиям сетки.

## Как устроено

| Что        | Чем                                              | Зачем                                                                            |
| ---------- | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| Интерфейс  | React + TypeScript                               | компоненты и типизированные данные проектов                                      |
| Сборка     | Vite                                             | быстрая сборка, изображения в AVIF/WebP (vite-imagetools)                        |
| Маршруты   | React Router + пререндер                         | у каждой страницы готовый HTML: прямые ссылки, заголовки и превью для соцсетей   |
| Стили      | CSS Modules + дизайн-токены                      | все цвета, размеры и отступы — в `src/styles/tokens.css`                         |
| Анимации   | GSAP (ScrollTrigger, SplitText)                  | грузится отдельно после показа страницы                                          |
| Тесты      | Playwright Test + axe-core                       | маршруты, адаптив, навигация, анимации, доступность, ссылки, изображения, анкета |
| Публикация | GitHub Actions → ветка `gh-pages` → GitHub Pages | автоматически после проверки                                                     |

```
src/
  content/        данные: проекты, услуги, подход, контакты, настройки сайта
  components/     общие компоненты: кнопки, сетка, рамки скриншотов, «чертёжные» элементы
  sections/       секции главной (home/) и страницы кейса (case/)
  pages/          страницы: главная, кейс, 404, дизайн-система (/system — только при разработке)
  motion/         движок анимаций и переходы между страницами
  styles/         токены, сброс стилей, типографика
scripts/          пререндер, картинки превью ссылок, иконки
tests/            автотесты
worker/           посредник для отправки анкеты в Telegram (Cloudflare Worker)
docs/             инструкции
```

## Как вносить изменения

Работа идёт через Claude Code и GitHub — с iPad или любого другого устройства.

1. Каждое изменение делается в отдельной ветке и оформляется pull request (PR).
2. Для каждого PR GitHub автоматически запускает проверку: типы, линтер, форматирование,
   сборка и автотесты в Chromium и Safari (WebKit). Результат виден в PR.
3. После слияния PR в `main` проверка запускается ещё раз и, если всё зелёное,
   **сайт публикуется сам** через 3–5 минут. Вручную выкладывать ничего не нужно.

История публикаций — в ветке `gh-pages` (каждая публикация отдельным коммитом)
и во вкладке **Actions** репозитория.

## Частые задачи

### Добавить новый проект

Подробно — в [docs/ADDING_A_PROJECT.md](docs/ADDING_A_PROJECT.md). Коротко:
скриншоты в `src/content/projects/<slug>/media/`, данные в `src/content/projects/<slug>/index.ts`,
строка в `src/content/projects/index.ts`, затем `npm run og` — картинка превью ссылки.
Карточка на главной, страница кейса, карта сайта и метаданные появятся сами.

### Добавить контакты

Файл `src/content/site.ts`, объект `contacts`:

```ts
export const contacts = {
  email: 'hello@example.com',
  channels: [
    { href: 'https://t.me/username', label: 'Telegram' },
    { href: 'https://github.com/tsum323', label: 'GitHub' },
  ],
};
```

Пока список пуст, в блоке «Контакт» и в подвале показывается нейтральный текст.

### Анкета и окно «Обсудить проект»

Кнопка «Обсудить проект» открывает окно с вариантами связи (контакты из `src/content/site.ts`)
и ссылкой на анкету `/brief`. Без JavaScript кнопка ведёт к блоку «Контакт».

- Вопросы и варианты ответов — `src/content/brief.ts`. Каждый вопрос можно пропустить,
  у каждого есть поле «своими словами».
- Отправка в Telegram идёт через посредника Cloudflare Worker (`worker/brief-worker.js`).
  Как его подключить — [docs/BRIEF_TELEGRAM.md](docs/BRIEF_TELEGRAM.md). Пока адрес
  посредника (`briefEndpoint`) не указан, клиент копирует ответы и отправляет их сам.
- Политика конфиденциальности — `src/pages/PrivacyPage.tsx`. Если меняется способ отправки
  заявок, текст политики нужно обновить.

### Поменять тексты

| Что                                 | Где                                    |
| ----------------------------------- | -------------------------------------- |
| Первый экран                        | `src/sections/home/Hero.tsx`           |
| Услуги («Делаю» / «Развиваю»)       | `src/content/services.ts`              |
| Этапы работы, принципы, инструменты | `src/content/approach.ts`              |
| Описание сайта для поисковиков      | `src/content/site.ts`                  |
| Тексты кейса                        | `src/content/projects/<slug>/index.ts` |
| Вопросы анкеты                      | `src/content/brief.ts`                 |

### Открыть сайт для поисковиков

Сейчас сайт **закрыт** от поисковиков (`noindex`) — до тех пор, пока он не будет готов.
Когда придёт время:

1. В `src/content/site.ts` поменять `indexable: false` на `indexable: true`.
2. После публикации добавить сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru/)
   и [Google Search Console](https://search.google.com/search-console) и отправить
   карту сайта: `https://tsum323.github.io/DWeb/sitemap.xml`.

Страница 404 остаётся закрытой всегда.

### Подключить свой домен

1. В `vite.config.ts` поменять `base: '/DWeb/'` на `base: '/'`.
2. В `src/content/site.ts` поменять `url` на адрес домена.
3. Добавить файл `public/CNAME` с доменом и настроить DNS
   [по инструкции GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).
4. В тестах (`tests/`, `playwright.config.ts`) заменить базовый путь `/DWeb` на корень —
   поиском по проекту.

## Команды

Нужен Node.js 22.

```
npm install          # установить зависимости
npm run dev          # разработка: http://localhost:5173/DWeb/ (и /DWeb/system — дизайн-система)
npm run build        # сборка в dist/ с готовыми HTML-страницами
npm run check        # типы, линтер, форматирование
npm test             # автотесты (нужна сборка; браузер — npx playwright install chromium)
npm run og           # пересоздать картинки превью ссылок (public/og/)
npm run icons        # пересоздать иконки из public/favicon.svg
```

## Принципы

- **Честность данных.** В кейсах — только факты: реализованное отдельно от планов,
  метрики — только с источником. Чего нет в данных, того нет на странице.
- **Контент виден всегда.** Без JavaScript, при «уменьшить движение» и при сбое загрузки
  анимаций страница показывается целиком.
- **Доступность.** WCAG 2.2 AA: проверяется автотестами на каждом PR.
