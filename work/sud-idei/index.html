Кейс/Веб-приложение с AI

Суд идей

Пиксельный AI-суд для идей: девять агентов оценивают идею, спорят друг с другом, а главный судья выносит вердикт и план действий.

Все работы

01/Задача

Контекст и задача

Идея кажется гениальной, пока её никто не критикует. Задача — инструмент, который смотрит на идею с разных сторон: рынок, деньги, техника, риски, — и честно говорит, стоит ли за неё браться.

Девять агентов с разными ролями независимо пишут заключения, затем проходит раунд перекрёстной критики, и главный судья выносит одно из четырёх решений: допустить, допустить условно, отправить на доработку или в «Тюрьму идей».

02/Дизайн

Концепция и дизайн

Зал суда в пиксельном стиле на одном экране: судья за трибуной, вокруг девять персонажей. Нажимаешь на персонажа — читаешь его заключение. Скучный разбор превращается в заседание, за которым интересно следить.

Персонажи нарисованы кодом по картам 16×16 пикселей и различаются аксессуарами: галстук прокурора, бабочка адвоката, каска архитектора. Пиксельный шрифт Press Start 2P в заголовках.

03/Реализация

Реализация

Next.js с серверной частью: заседание идёт по этапам, агенты работают параллельно, результаты сохраняются в SQLite. Ответы модели проверяются по схемам, общий балл — взвешенное среднее 10 критериев.

Для реальной работы подключается Claude API, ключ остаётся только на сервере. Есть бесплатный демо-режим без сети: заключения строятся шаблонами, и интерфейс прямо об этом предупреждает. Если один агент упал, его можно перезапустить отдельно. 44 автотеста.

06/Результат

Результат и ограничения

Известные ограничения

  • Реальные вызовы Claude API ещё не проводились; скриншоты сняты в демо-режиме, где заключения строятся шаблонами.
  • Общий балл — ориентир, а не вероятность успеха идеи.
  • Инструмент для одного человека: входа и нескольких пользователей нет.

Реализовано

  1. 01

    Девять ролей и судья

    Прокурор, адвокат, рыночный и финансовый эксперты, архитектор, продукт, привлечение, риски, независимый эксперт.

  2. 02

    Перекрёстная критика

    Отдельный этап находит главные противоречия между заключениями.

  3. 03

    Вердикт и план

    Балл из 100, три главных риска, аргументы и план действий; отчёт копируется в Markdown.

  4. 04

    «Тюрьма идей» и пересмотр

    Отклонённую идею можно вернуть только с новыми основаниями — тогда начинается новый раунд.

  5. 05

    Демо-режим

    Работает без сети и бесплатно, чтобы показать процесс; честно помечен в интерфейсе.

Следующие шаги
