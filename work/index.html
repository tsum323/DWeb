6 проектов: сайты для бизнеса и веб-приложения. Коротко о каждом здесь, подробно, со скриншотами — на странице проекта.

    TEHNIKA

    Каталог техники с ценами за час и админ-панель, где видно заявки, оплаты, занятость машин и прибыль.

  • P/02Веб-приложение

    Personal Dashboard

    Проекты, деньги, задачи и идеи на одном экране — на стеклянных панелях поверх своей фотографии. Без сервера: данные остаются в браузере.

    • TypeScript

    Brass Barbershop

    • Демо
    • HTML
    • CSS
    • JavaScript

  • P/04Аналитическое веб-приложение

    Трейдинг-терминал

    Терминал, который проверяет торговые идеи строже, чем хочется: графики, расчёт риска и девять виртуальных трейдеров без реальных денег.

    • Next.js
    • TypeScript
    • Lightweight Charts

    • Next.js
    • TypeScript
